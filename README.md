# Richie Patil's Portfolio 🚀

A modern, interactive portfolio website built with love using cutting-edge web technologies. This project showcases smooth animations, responsive design, and contemporary web development practices.

## 🛠 Tech Stack

- **[Next.js 15](https://nextjs.org)** - React framework with App Router
- **[TypeScript](https://www.typescriptlang.org/)** - Type-safe JavaScript
- **[Tailwind CSS](https://tailwindcss.com/)** - Utility-first CSS framework
- **[GSAP](https://greensock.com/gsap/)** - Professional-grade animation library
- **[React 19](https://react.dev/)** - Latest React features

## 🚀 Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

The portfolio features smooth GSAP animations and responsive Tailwind CSS styling. You can start customizing by modifying `app/page.tsx`.

## ✨ Features

- 🎨 **Smooth Animations** - Powered by GSAP for professional-grade motion design
- 📱 **Responsive Design** - Optimized for all devices using Tailwind CSS
- ⚡ **Performance Optimized** - Built with Next.js 15 and modern React patterns
- 🎯 **Type Safe** - Full TypeScript implementation
- 🚀 **Fast Development** - Hot reload with Turbopack support
